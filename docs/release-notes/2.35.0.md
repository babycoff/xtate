# Xtate 2.35.0

This release makes the offline and local test infrastructure a first-class part
of the project, and hardens ZBanner's receive path.

## Highlights

- Generic offline pcap toolkit and six pcap regression matrices.
- Local TLS/H2 and QUIC/HTTP3 nightly lab.
- Decrypted HTTP/3 frame fixture (QPACK static table).
- ZBanner classification caching, `banner dedup_repeat` and payload-contract
  diagnostics.
- Version/reporting consistency.

## Offline pcap toolkit

New `tests/pcap/lib.py` builds deterministic Ethernet/IPv4/IPv6 TCP and UDP
packets, checksums, Xtate cookies and pcap files for the receive-only `file:`
adapter. Suites:

| Suite | Coverage |
|:---|:---|
| `tests/zbanner` | SYNACK/RST/banner/retransmit/all-banner limit+floor/IPv6/zero-window/payload mismatch |
| `tests/http-pcap` | HTTP keyword/regex/scope/case/no-match |
| `tests/tcp-syn-pcap` | SYN-ACK/RST |
| `tests/http-state-pcap` | recorded plaintext stateful HTTP |
| `tests/h2c-pcap` | cleartext HTTP/2 frames |
| `tests/udp-pcap` | UDP echo cookie response |

The matrices run in release CI and need no network, root, firewall or target
container.

## Encrypted protocol testing

- `tests/lab/ci-h2.sh`: local TLS HTTP/2 target; status/header/body.
- `tests/lab/ci-quic.sh`: local aioquic HTTP/3 target; status/body/matching.
- `.github/workflows/lab-encrypted.yml`: nightly/manual run.
- `tests/http3-frame/`: decrypted HEADERS/DATA fixture and `h3_frame_selftest()`
  in `http3-state`, exercising QPACK static lookup without QUIC/TLS.
- TLS/QUIC pcap replay is intentionally not supported: encrypted handshakes need
  client/transcript state that a pcap does not contain.

## ZBanner

- Shared `zb_classify()` used by validate/handle; classification cached in
  `ValidPacket` so handle does not parse the same packet again.
- `zbanner-policy.c` centralizes all-banner limit/floor/RST/ACK/truncated rules
  with a startup self-test.
- `AfterFirstReply` remains a dedup-counter one-shot (`repeats == 0`); with
  dedup disabled it may fan out again, as documented.
- Banner/ACK validation uses the actual `make_payload()` length. A mismatch
  emits `payload_len_declared`, `payload_len_actual` and
  `payload_contract_error`.
- `banner dedup_repeat` is an explicit alias of `banner idx`; `banner seqno` is
  the reliable ordering field.
- `--all-banner-limit`/`--all-banner-floor` are bounded and floor>limit is
  rejected.

## Known limitations

- TLS/QUIC pcap replay is not provided.
- H2/QUIC nightly uses local Docker targets, not file-only pcap.
- Dynamic QPACK, HTTP/3 push/CONNECT/WebTransport and Windows quic-state remain
  unsupported/roadmap items.
