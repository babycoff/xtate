# Xtate 3.0.0-rc.9

Release candidate. This build is feature-identical to 3.0.0-rc.8; it fixes the
release pipeline so that tagged builds produce downloadable assets with
provenance.

## Release engineering fixes

- The release workflow now creates `reports/docker-out` before exporting the
  Linux binary from the full-feature Docker image.
- Linux package provenance accepts an explicit commit through
  `XTATE_COMMIT` when Git metadata is unavailable inside a container.
- GitHub Actions release workflow packages both Windows and Linux artifacts
  from the tag and uploads them to the GitHub pre-release.

## Verification

- Windows MSVC build, selftest, full regression suite (MCP, MCP contract,
  MCP stability, Agent Skill contract, GUI, control, generate, scan-request,
  i18n, schema/module validators, version consistency).
- Linux full-feature Docker image: HTTP/3, QUIC, zstd and raw sockets enabled;
  MCP, GUI, control and integration tests pass.
- Docs relative-link check passes.

## Compatibility

No CLI, MCP or GUI behavior changes from 3.0.0-rc.8. Existing result files and
configuration remain compatible.

## Known limitations

The limitations documented for 3.0.0-rc.8 still apply: some review P2/P3 items
remain deferred, Windows HTTP/3/QUIC is reported unavailable, and the GUI is
local-first with explicit remote opt-in.
