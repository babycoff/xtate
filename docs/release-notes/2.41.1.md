# Xtate 2.41.1

Documentation release for the 2.41.x line.

## README

- Highlights Xtate's protocol coverage: HTTP/1.0/1.1, HTTP/2 with HPACK
  (including Huffman), HTTP/3 over QUIC, HTTPS/TLS, DNS over UDP, DNSSEC
  evidence, DoT, DoH HTTP/1.1 and DoH HTTP/2.
- Adds the scoped Linux/Windows firewall guidance from 2.41.0.

## Documentation

- Adds the AI integration roadmap and design:
  - JSON contracts + Agent Skill (2.42.0);
  - read-only MCP server (2.43.0);
  - controlled scan jobs over MCP (2.44.0);
  - agent evaluation and packaging (2.45.0).
- Adds `docs/ai-integration.md` and the Chinese translation.

No runtime code changes in this release.
