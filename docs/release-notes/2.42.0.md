# Xtate 2.42.0

## Highlights

- Managed scan jobs: timeout, stall detection, heartbeat, cancellation, retention.
- Control plane over Unix socket or Windows Named Pipe with `XTATE_CONTROL_TOKEN`.
- Control/data split: control responses carry metadata only; results stay in chunked NDJSON manifests.
- Chunked result store with optional index, zstd and quota.
- MCP stdio server: `list_modules`, `describe_probe`, `explain_target`, `check`, `validate_config`, `start_scan`, `job_*`.
- Route-aware `explain_target`/`check` with IPv4/IPv6 grouping and mixed-route rejection in `start_scan`.
- End-to-end MCP tests.
