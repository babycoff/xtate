# Xtate 2.41.0

Adds DNS over TLS, DNS over HTTPS (HTTP/1.1 and HTTP/2), HPACK Huffman
decoding, a repeatable DNS transport lab, and scoped firewall guidance.

## DNS probes

### DoT

New `dot` state sub-probe:

```text
tcp-state -> tls-state (ALPN dot) -> dot
```

Sends the RFC 7858 two-byte length prefix and parses the DNS response:

```text
dot_dns_len
dot_rcode
dot_ad
dot_answer
dot_rrsig_count
dot_dnskey_count
dot_ds_count
dot_nsec_count
dot_dnssec_present
```

### DoH

New `doh` (HTTP/1.1) and `doh-h2` (HTTP/2):

```text
doh:    tcp-state -> tls-state (ALPN http/1.1) -> doh
doh-h2: tcp-state -> tls-state (ALPN h2)       -> doh-h2
```

Both POST `application/dns-message` and report:

```text
doh_status
doh_content_type
doh_dns_len
doh_rcode
doh_ad
doh_answer
doh_rrsig_count
doh_dnskey_count
doh_ds_count
doh_nsec_count
doh_dnssec_present
```

`doh-h2` includes the shared HTTP/2 HPACK decoder with RFC 7541 Huffman
support. `--doh-host` defaults to the target IP; `doh-h2` defaults its path to
`/dns-query` in DoH mode.

## Tests and firewall

- `tests/lab/ci-dns-transport.sh` starts DoT, DoH HTTP/1.1 and DoH HTTP/2
  targets and asserts `dot_rcode`, `doh_status: 200`, and absence of
  `h2_hpack_decode_failed`.
- Linux firewall guidance is scoped to stateful scans (`zbanner`,
  `tcp-state`, state sub-probes). `tcp-syn` and UDP/DNS do not require the
  Linux RST rules.
- On Windows Xtate prints no firewall warning; `tcp-syn` prints only the
  `-scan-arg "--send-rst"` hint.
- Documentation: `docs/firewall.md`, `docs/dns-over-tls.md`,
  `docs/dns-over-https.md` (English and Chinese).

## Caveats

- DoH HTTP/3 is not implemented.
- DoT/DoH are state sub-probes and require `tls-state`.
- DNSSEC fields are deployment evidence, not full chain validation.
