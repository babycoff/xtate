# Xtate 2.37.0

Adds the Batch B database, mail and file-service probes.

## New probes

| Protocol | tcp version | state version |
|:---|:---|:---|
| MySQL | `mysql` | `mysql-state` |
| PostgreSQL | `postgres` | `postgres-state` |
| MongoDB | `mongodb` | - |
| SMTP | `smtp` | `smtp-state` |
| IMAP | `imap` | `imap-state` |
| POP3 | `pop3` | `pop3-state` |
| FTP | `ftp` | `ftp-state` |
| ManageSieve | `managesieve` | `managesieve-state` |

The tcp variants are intentionally banner/capability-minimal for high-rate
first-pass filtering: MySQL greeting, PostgreSQL SSLRequest, MongoDB OP_MSG
hello, and the SMTP/IMAP/POP3/FTP/ManageSieve server greeting.

The state variants read capabilities or the PostgreSQL auth boundary through
`tcp-state`. No probe sends credentials, authenticates, publishes, sends mail,
runs queries or changes clocks.
