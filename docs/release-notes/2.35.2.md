# Xtate 2.35.2

Patch release for sanitizer/fuzzer findings and quality infrastructure.

## Fixes

- **TCP zero-length payload**: avoid `memcpy(NULL, 0)` on RST/no-payload paths
  (IPv4 and IPv6).
- **TCP sequence/ack extraction**: cast bytes to unsigned before shifting;
  removes UBSan signed-shift undefined behavior.
- **HTTP/2 HPACK integer decoding**: reject shift/size overflow instead of
  invoking undefined behavior on malformed input.

## Quality infrastructure

- ASan + UBSan clang build job, selftest and six pcap matrices.
- `h3_qpack_fuzz` and `h2_hpack_fuzz` libFuzzer harnesses for the in-tree
  HTTP/3 QPACK and HTTP/2 HPACK parsers.
- H2/H3 fuzz seeds and test-only parser guards.
- Fuzz smoke integrated into CI.
