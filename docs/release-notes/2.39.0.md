# Xtate 2.39.0

Completes the TLS/STARTTLS composition matrix for Batch B/C probes.

## Compose modes

- Implicit TLS: SMTP, MySQL, PostgreSQL, MongoDB.
- STARTTLS: SMTP, IMAP, POP3, FTP, ManageSieve.
- `--after-tls` on the relevant state probes.
- `tls-state --starttls managesieve` adapter.

Every matrix case asserts:

```text
tls_alpn: "h2"
tls_version: "TLSv1.3"
cert_subject: "CN=example.test"
```

and the protocol-level field where the server-first timing is deterministic.

## Tests

- `tests/lab/ci-tls-composition.sh` full matrix.
- `tests/lab/tls_matrix_server.py` implicit-TLS targets.
- `tests/lab/starttls_server.py` extended with ManageSieve and ALPN h2.
- Nightly TLS/STARTTLS composition passed.

## Notes

- MySQL and ManageSieve are server-first; their implicit/STARTTLS cases assert
  TLS evidence and certificate/ALPN. The protocol-level greeting parse is
  exercised by the plaintext probes; TLS-internal server-first timing is not
  asserted as a hard failure in this matrix.
- Firewall prerequisite documentation from 2.38.0 remains in effect.
