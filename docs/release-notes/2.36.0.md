# Xtate 2.36.0

Adds six protocol-aware probes and their local fake-server lab.

## New probes

| Probe | Engine | What it reports |
|:---|:---|:---|
| `redis` | TCP | read-only `INFO server`; version, mode, OS, role |
| `memcached` | TCP | `version`; server version |
| `ntp` | UDP | mode-3 request; leap/version/stratum/refid/root fields and cookie validation |
| `mqtt` | TCP | MQTT 3.1.1 CONNECT/CONNACK; return code and session-present |
| `socks5` | state | greeting and method selection |
| `telnet` | state | initial banner and IAC WILL/WONT/DO/DONT options |

No credentials, writes, publishes, CONNECTs or clock changes are sent.

## Testing

- `tests/lab/ci-probes.sh` with local Redis/Memcached/NTP/MQTT/SOCKS5/Telnet
  fake servers.
- Nightly protocol probe lab.
- English/Chinese help and protocol-coverage docs.
- Module count: 11 base Scan + 33 Probe + 7 Output + 5 Generate.

  release tree.
