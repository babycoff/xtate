# Xtate 3.0.0-rc.6

**Release candidate — for hands-on trial, not the final 3.0.0.**

This candidate hardens the MCP/Agent Skill contract and adds the reproducible
Ubuntu 24.04 full-feature Docker build.

## MCP and Agent Skill

- `start_scan` now uses a flat schema. Scan-request fields are passed directly
  as the tool arguments; the obsolete nested `{"arguments":{...}}` example is
  rejected with a clear `unknown field: arguments` diagnostic.
- Unknown request fields are rejected server-side instead of being ignored.
  `global_args` is restricted to the 23 GUI-safe options and is validated for
  type, length and range.
- `preflight` accepts either JSON arrays or the GUI's comma-separated strings
  for `targets` and `ports`. Both forms return the same result.
- Tool arguments over 8 KiB return
  `request too large; keep tool arguments under 8 KiB or use include_file`
  instead of a misleading authorization/path error.
- `check` now performs the actual `--check` pass and reports link capability;
  Linux firewall inspection remains a separate `xtate://docs/firewall` resource.
- Control-plane tokens are JSON-escaped on the MCP side and decoded on the
  control-plane side, so tokens containing `"` or `\` work.
- Added `tests/mcp/test_mcp_contract.py` and `tests/skill/test_skill_contract.py`
  covering schemas, framing, arrays/strings, unknown fields, oversize recovery,
  token escaping and Agent Skill examples.

## Ubuntu 24.04 full-feature Docker build

- New `docker/ubuntu24-build/Dockerfile` installs every optional Ubuntu 24.04
  dependency: OpenSSL, PCRE2, LibXml2, libbson/libmongoc, ngtcp2+GnuTLS, zstd,
  libpcap and Lua 5.3.
- The build asserts `http3`, `quic_transport`, `zstd`, `raw_sockets` and
  12 scan modules before producing the image.
- `build.sh` supports `official`, `tuna`, `ustc`, `aliyun` and `huawei` APT
  mirrors and a mainland-friendly base image.
- Host GUI access is explicit: `-e XTATE_GUI_ALLOW_REMOTE=1`, host-loopback
  port publishing and an optional `XTATE_GUI_PUBLIC_URL` for the printed URL.
- The image sets `XTATE_MCP_DOCS_DIR=/usr/local/share/xtate` and
  `XTATE_STATE_DIR=/data`; mount `/data` to keep run results.
- `docs/docker-build.md` and the Chinese translation document builds, mirrors,
  capability checks, host GUI access, raw scans and MCP.
- Linux libpcap soname probing no longer logs expected missing candidates as
  warnings.

## Compatibility

- No result-format change.
- The old nested `start_scan` form is rejected. Update clients and the Agent
  Skill to pass scan-request fields directly.
- `--gui` still never launches a browser; open the printed URL manually.
- TUI remains deprecated and is not part of 3.0.

## Verification

- Windows MSVC Release build and full test suite: pass.
- Linux Ubuntu 24.04 build and full test suite: pass.
- Docker image `xtate:ubuntu24-full`: build, selftest, capability assertions,
  host GUI page/API, preflight, `tcp-syn` job and MCP stdio handshake tested.
- Independent Agent Skill contract re-test: 7/7 pass.
- Documentation relative links: 0 broken.

## Known limitations

- A sandbox without named-pipe access cannot exercise the full MCP job lifecycle;
  that case is reported as blocked, not passed.
- `preflight` does not support `include_file`; use `explain_target` for route
  checks and reserve file input for large starts.
- The Docker image cannot open a file picker or the host's result viewer. Use
  the mounted `/data` path or the GUI Results page.
- Final 3.0.0 remains gated on user trial and sign-off.
