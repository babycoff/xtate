# Xtate 3.0.0-rc.10

Release candidate. This build is feature-identical to 3.0.0-rc.9; it fixes the
remaining tagged-release packaging failures so that the release workflow can
produce and publish downloadable assets end to end.

## Release engineering fixes

- Linux packaging reads capabilities from the built Docker image instead of
  executing the dynamically linked binary on the runner.
- Windows release packaging now parses the version robustly from `--version`.
- The release workflow creates the Docker export directory before copying the
  Linux binary, and both platform artifacts are uploaded to the GitHub
  pre-release with checksums.

## Verification

- All branch CI jobs are green for this commit: Linux gcc/clang release and
  debug, clang ASan+UBSan, parser fuzz smoke, integration, Docker image;
  Windows MSVC, clang-cl and MinGW UCRT64/MINGW64.
- Windows full regression and Linux full regression from the preceding rc9
  source pass; this build changes packaging only.
- Tagged release workflow builds both platforms and publishes assets.

## Compatibility

No CLI, MCP or GUI behavior changes from 3.0.0-rc.9. Existing result files and
configuration remain compatible.

## Known limitations

The limitations documented for 3.0.0-rc.9 still apply. The Linux release binary
links the distribution libraries available in the Ubuntu 24.04 image; the
Docker image remains the fully self-contained option.
