# Xtate 2.35.2

本补丁版修复 sanitiser/fuzzer 发现的问题，并加入质量基础设施。

## 修复

- **TCP 零长度 payload**：RST/无 payload 路径不再 `memcpy(NULL, 0)`（IPv4/IPv6）。
- **TCP sequence/ack 提取**：先转 unsigned 再移位，消除 UBSan 有符号移位未定义行为。
- **HTTP/2 HPACK 整数解码**：拒绝移位/`size_t` 溢出，而不是进入未定义行为。

## 质量设施

- clang ASan + UBSan job、selftest 和 6 套 pcap 矩阵。
- `h3_qpack_fuzz` 与 `h2_hpack_fuzz` libFuzzer harness，针对仓库内的 HTTP/3 QPACK 与 HTTP/2 HPACK parser。
- H2/H3 fuzz seed 与 test-only parser guard。
- fuzz smoke 接入 CI。
