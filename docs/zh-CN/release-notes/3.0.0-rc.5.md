# Xtate 3.0.0-rc.5

发布日期：2026-11-14

本候选版本是 3.0 控制台的易用性与验证完善版，不改变扫描引擎和线上数据格式。

## 相对 3.0.0-rc.4 的变化

### 控制台不再自动启动浏览器

`xtate --gui` 现在只打印 URL、私有控制端点和每会话 token，然后等待。它不会调用
`ShellExecute`、Explorer 或任何浏览器进程。请自行用喜欢的浏览器打开打印出的地址。

旧的 `--gui-no-open` 参数仅为脚本兼容而保留，已弃用且不再产生效果。

### 更快的 Open log / Open result

在 Windows 上，**Open log** 与 **Open result** 现在直接用 `CreateProcessW` 和已解析
的 job 路径启动 Notepad，不再等待 ShellExecute/DDE/Explorer 的文件关联解析。本地
测量中 `/api/open` 请求在 224 ms 内返回（包含 PowerShell 客户端开销）。

服务端仍然从 job 自身的状态/manifest 解析路径，从不接受客户端提供的路径。

### 完整模块帮助与探针传输类型

展开后的模块卡片会显示完整长描述和完整参数表。探针模块（以及需要探针的扫描）
会显示传输类型徽标：`TCP`、`UDP` 或 `TCP · 有状态`，并附带翻译后的
`Probe type` 行。模块页保持真实的 Xtate 分类：

- 扫描模块
- 探针模块
- 输出模块
- 生成模块

### README 与项目门面

中英文 README 已围绕 3.0 体验重写：RC 状态、从这里开始表格、控制台截图、当前模块
数量、GUI 与 MCP 入口、有界 `job.records`，以及新的协议/能力报告。README 不再宣传
自动打开浏览器，也不再宣传已弃用的 TUI 工作流。

### MCP 与 Agent Skill 契约修复

独立 MCP 契约复查发现 3 个阻断级不一致，rc.5 已修复：

- `start_scan` 改为扁平输入 schema；工具参数直接是扫描请求字段，客户端不再额外
  包一层 `arguments`。skill 与示例已同步。
- `preflight` 同时接受 JSON 数组和逗号分隔字符串形式的 `targets`/`ports`，
  与 MCP 客户端和 GUI 表单都一致。
- 超过 8 KiB 行缓冲区的 tools/call 请求现在返回明确的
  `request too large; ... use include_file`，不再误报授权失败。

`validate_config` 与 `start_scan` 会拒绝未知扫描请求字段；MCP 在转发前校验
`global_args` 的值。

### 构建环境计划

3.0 roadmap 新增 Ubuntu 24.04 满血构建环境：包含全部可选依赖的 Docker 镜像、
中国大陆软件源选择、Linux 能力 smoke test，以及容器内 GUI 的宿主机访问方案。
这是下一阶段基础设施计划，不属于本候选版本的二进制。

## 兼容性

扫描请求与结果 schema 未变。rc.4 写出的 job 和 manifest 仍可读取。
`--gui-no-open` 仍被接受但已弃用。若旧脚本依赖 GUI 自动打开浏览器，请改为自行打开
打印出的 URL。

## 已知限制

- HTTP/3 与 QUIC transport 仍仅在 Linux + ngtcp2/GnuTLS 构建中可用；Windows 报告为
  不可用。
- GUI 默认把结果写到可见的 `<exe-dir>/xtate-state/runs/`；可执行文件目录不可写时
  回退到用户状态目录。
- GUI 暴露的全局参数仅限审计过的 23 项 allowlist，其余参数仍只支持 CLI。
- 结果浏览每次最多 200 条。
- 控制面仍仅限本机；显式启动的 daemon token 可选，但私有 GUI/MCP/TUI 控制面会自动
  生成临时 token。
- Ubuntu 24.04 构建镜像属于计划，本候选版本未附带。

## 试用重点

请在 Windows 和 Linux 上试用 GUI：

1. `xtate --gui`，打开打印出的地址，切换 English/中文。
2. 启动一个小范围授权扫描，确认 Live 状态、计数、日志尾部和有界记录。
3. 使用 **Open log** 与 **Open result**，确认能立即打开。
4. 展开若干扫描/探针模块，检查完整帮助与探针类型。
5. 如有条件，运行一个 MCP 客户端和 Agent Skill 工作流。

正式 3.0.0 将等待现场试用反馈后再发布。
