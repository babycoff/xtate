# Xtate 2.37.0

新增 Batch B 数据库、邮件和文件服务探针。

## 新探针

| 协议 | tcp 版本 | state 版本 |
|:---|:---|:---|
| MySQL | `mysql` | `mysql-state` |
| PostgreSQL | `postgres` | `postgres-state` |
| MongoDB | `mongodb` | - |
| SMTP | `smtp` | `smtp-state` |
| IMAP | `imap` | `imap-state` |
| POP3 | `pop3` | `pop3-state` |
| FTP | `ftp` | `ftp-state` |
| ManageSieve | `managesieve` | `managesieve-state` |

tcp 版本刻意只读取 banner/最少能力，适合大规模快速第一轮筛选；state 版本
通过 `tcp-state` 读取能力或 PostgreSQL 认证边界。所有探针都不发送凭据、
不认证、不 publish、不发邮件、不执行查询、不修改时钟。
