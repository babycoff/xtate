# Xtate 2.42.0

## 重点

- 托管扫描 job：超时、stall 检测、heartbeat、取消和保留策略。
- Unix socket / Windows Named Pipe 控制面，支持 `XTATE_CONTROL_TOKEN`。
- 控制面与数据面分离：控制响应只带元数据，结果保留在分片 NDJSON manifest。
- 分片结果存储，可选索引、zstd 和配额。
- MCP stdio server：`list_modules`、`describe_probe`、`explain_target`、`check`、`validate_config`、`start_scan`、`job_*`。
- `explain_target`/`check` 支持 IPv4/IPv6 路由分组，MCP `start_scan` 拒绝混合路由。
- MCP 端到端测试。

## 已知限制

在 Windows 上，控制面的 job（control jobs）使用 ANSI `CreateFileA` 创建结果文件，建议使用相对
ASCII 的 result_path（例如 `results/scan.ndjson`）；包含非 ASCII 目录名的绝对路径
返回 ACCESS_DENIED。该限制适用于 2.42.0 标签；标签之后已修复，当前构建使用
Windows 宽字符 API，支持绝对 Unicode result_path。
