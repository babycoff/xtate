# Xtate 2.35.1

本补丁版聚焦加密协议正确性和测试深度。

## HTTP/3 QPACK 修复

`http3-state` 现在能正确解码 QPACK **Literal Field Line with Literal Name**：

```text
001 N H NameLen(3+)
```

`H` 是 `0x08`，`N` 是 `0x10`。旧代码把 `N` 位当成 Huffman 位，导致 literal
header name 乱码，例如输出 `�|���` 而不是 `x-extra`。

本版还在 `h3_frame_selftest()` 中加入 QPACK Huffman 帧 fixture，在不依赖
QUIC/TLS 的情况下覆盖 H-bit 和 Huffman literal 路径。

## 测试深度

- TLS/H2：status 404、空 DATA、额外 header、多 HEADERS、matcher、证书
  subject、TLS 版本和 ALPN `h2`。
- H2C：`--all-frames`、`--settings-hex`、`--ping-hex`、`--no-ping`、
  `--no-settings`。
- HTTP/3：body/header/no-match、status 404、空 body、额外 header。
- UDP：IPv4/IPv6 echo 和 ICMP/ICMPv6 port unreachable。
- HTTP-state：all-banner 和匹配。
- H2C 合成 pcap 矩阵保持稳定。

## Nightly 稳定性

加密协议 nightly workflow 现在：

- 修复 H2 source-IP 提取；
- 使用 H2 目标期望的证书路径；
- 匹配带引号的 `h2_status: "200"`；
- 失败时保留并上传日志；
- 增加扫描超时和目标就绪检查；
- 使用 `docker/build-push-action` 缓存目标镜像。

## 已知限制

- H2C pcap 测试不覆盖 settings/ping，因为这些配置会改变客户端 payload 长度，
  需要逐配置生成 ZBanner ACK fixture；settings/ping 由 live H2C depth 脚本覆盖。
- TLS/QUIC pcap 原样回放仍有意不支持。
- Dynamic QPACK、HTTP/3 push/CONNECT/WebTransport、Windows quic-state 不变。
