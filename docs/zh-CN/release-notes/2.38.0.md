# Xtate 2.38.0

新增 Batch B state 探针的 TLS/STARTTLS 组合，以及 Batch C 第一批协议。

## 新增

- `smtp-state`、`imap-state`、`pop3-state`、`ftp-state`、`postgres-state`
  新增 `--after-tls`，用于在 `tls-state`（隐式 TLS 或 STARTTLS）内部组合。
- `mongodb-state`，用于 MongoDB 隐式 TLS。
- `ipp` / `ipp-state`：未认证 IPP Get-Printer-Attributes。
- `amqp` / `amqp-state`：AMQP 0-9-1 protocol header/Connection.Start。
- `pptp` / `pptp-state`：PPTP SCCRQ/SCCRP。
- TLS/STARTTLS 组合 lab 和 Batch C 协议 lab。

## 关键文档修复

TLS 组合 lab 最初失败，是因为扫描容器没有执行 `firewall/add_rules.sh`。这与
用户常犯的错误完全同类：内核 RST 会打断 raw HLTCP/TLS 连接，扫描器只输出
`open`，没有 banner/TLS/探针结果。

现在以下文档都明确强调 Linux 防火墙规则是前置条件：

- README 与 README.zh-CN；
- getting-started；
- troubleshooting；
- HLTCP；
- known-limitations；
- testing 与 lab README。

覆盖 `zbanner`、`tcp-state`、`tls-state`、HTTP/2/HTTP3 和所有 state 子探针，
不只 ZBanner。
