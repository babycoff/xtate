# Xtate 2.36.0

新增六个协议感知探针及本地 fake-server lab。

## 新探针

| 探针 | 引擎 | 输出 |
|:---|:---|:---|
| `redis` | TCP | 只读 `INFO server`；version/mode/os/role |
| `memcached` | TCP | `version`；服务器版本 |
| `ntp` | UDP | mode-3 请求；leap/version/stratum/refid/root 字段和 cookie 校验 |
| `mqtt` | TCP | MQTT 3.1.1 CONNECT/CONNACK；return code/session-present |
| `socks5` | state | greeting 和方法选择 |
| `telnet` | state | 初始 banner 和 IAC WILL/WONT/DO/DONT |

不发送凭据、写操作、publish、CONNECT 或时钟修改。
