# Xtate 3.0.0-rc.10

候选版本。本构建与 3.0.0-rc.9 功能一致，修复了带标签发布剩余的打包问题，使发布工作流能够端到端生成并发布可下载资产。

## 发布工程修复

- Linux 打包改为从构建好的 Docker 镜像读取 capabilities，不再在 runner 上直接运行动态链接的二进制。
- Windows 发布打包改为健壮解析 `--version`。
- 发布工作流在复制 Linux 二进制前创建 Docker 导出目录；两个平台的产物与校验和会一起上传到 GitHub 预发布。

## 验证

- 本提交的全部分支 CI 均通过：Linux gcc/clang release/debug、clang ASan+UBSan、parser fuzz smoke、集成测试、Docker 镜像；Windows MSVC、clang-cl、MinGW UCRT64/MINGW64。
- 前一版 rc9 源码的 Windows 与 Linux 完整回归通过；本构建仅变更打包。
- 打标签后发布工作流会构建双平台并发布资产。

## 兼容性

CLI、MCP 与 GUI 行为相对 3.0.0-rc.9 无变化。现有结果文件与配置保持兼容。

## 已知限制

3.0.0-rc.9 记录的限制仍然适用。Linux 发布二进制链接 Ubuntu 24.04 镜像中的发行版库；完整自包含运行仍推荐 Docker 镜像。
