# Xtate 2.41.2

JSON 契约和错误处理加固。

## 扫描请求

- `xtate --scan-request=request.json` 在 C 内解析封闭 JSON 请求并执行，
  不经过 shell 或子进程。
- target 在 CLI 解析前校验；非法 target 返回 `TARGET_INVALID`。
- Linux 缺少 RST/ICMP 规则时，scan-request 以
  `FIREWALL_RULES_MISSING` 中止。
- `dry_run` 映射为目标列表，不发送报文。

## 错误码

- 新增 `error-code.h`，错误码目录冻结在 `schemas/error-codes.json`。
- `--scan-request` 的错误以 JSON envelope 输出：
  `{"error":{"code":"...","message":"...","retryable":...}}`。
- `PERMISSION_DENIED`、`OUTPUT_WRITE_FAILED`、`FIREWALL_RULES_MISSING`
  已由真实路径使用。

## 输出

- 所有文件输出模块使用 `out_fprintf`/`out_fputc`/`out_fwrite`。
- 写入、flush、close 失败设置 `OUTPUT_WRITE_FAILED`，标记 fatal，退出非零。
  MongoDB 使用 `mongo_fail()`。
- 端到端测试：`tests/schema/test_output_failure.sh`。

## 体验

- 选择 OutputModule 但未指定 `--show` 时输出提示；支持 `--show all`。
- `--list-modules-json` 输出模块元数据，供 JSON 契约校验。
