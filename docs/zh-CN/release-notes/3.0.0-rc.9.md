# Xtate 3.0.0-rc.9

候选版本。本构建与 3.0.0-rc.8 功能一致，修复发布流水线，使打标签的构建能够生成带来源信息的可下载产物。

## 发布工程修复

- 发布工作流在从全功能 Docker 镜像导出 Linux 二进制前，先创建 `reports/docker-out` 目录。
- 容器内没有 Git 元数据时，Linux 打包脚本支持通过 `XTATE_COMMIT` 显式指定提交。
- GitHub Actions 发布工作流会从标签构建 Windows 与 Linux 产物，并上传到 GitHub 预发布。

## 验证

- Windows MSVC 构建、selftest、完整回归（MCP、MCP contract、MCP stability、Agent Skill contract、GUI、control、generate、scan-request、i18n、schema/module 校验、版本一致性）。
- Linux 全功能 Docker 镜像：HTTP/3、QUIC、zstd 与 raw sockets 均启用；MCP、GUI、control 与集成测试通过。
- 文档相对链接检查通过。

## 兼容性

CLI、MCP 与 GUI 行为相对 3.0.0-rc.8 无变化。现有结果文件与配置保持兼容。

## 已知限制

3.0.0-rc.8 记录的限制仍然适用：部分审查 P2/P3 项延期，Windows 的 HTTP/3/QUIC 明确报告不可用，GUI 默认本地使用并需显式开启远程访问。
