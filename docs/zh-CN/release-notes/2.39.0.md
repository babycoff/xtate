# Xtate 2.39.0

完成 Batch B/C 探针的 TLS/STARTTLS 组合矩阵。

## 组合模式

- 隐式 TLS：SMTP、MySQL、PostgreSQL、MongoDB。
- STARTTLS：SMTP、IMAP、POP3、FTP、ManageSieve。
- 相关 state 探针支持 `--after-tls`。
- `tls-state --starttls managesieve` 适配。

每条矩阵用例断言：

```text
tls_alpn: "h2"
tls_version: "TLSv1.3"
cert_subject: "CN=example.test"
```

并在时序确定的场景断言协议字段。

  证书/ALPN，协议级 greeting 由明文探针覆盖；TLS 内 server-first 时序不作为
  硬失败断言。
