# Xtate 2.40.1

在 2.40.0 之后强化输入/输出处理。

## 输出正确性

- NDJSON 字符串做 JSON 转义（引号、反斜杠、控制字符）。
- CSV 改为 RFC4180 风格：所有字段加引号，内部引号双写，报告列是合法的 JSON 字符串。
- CSV 追加模式不再重复写表头。
- BSON 输出检查 UTF-8/日期/int32/int64/double/bool/binary 附加结果。
- text/CSV/NDJSON/BSON 记录 `fflush`/`fclose` 失败。
- BSON 输出检查分配失败和短写。

## 输入加固

- BSON 输入拒绝超过 16 MiB 的文档并检查分配。
- `--parse-bson` 对损坏输入返回非零。
- 目标文件拒绝超过 65535 字节的行，不再拆分。
- 目标文件报告读取错误。
- 过长的 `--output-file` 直接报错，不再静默截断。
- Mongo BSON 导入统计插入失败和批量失败。

## 测试

- `tests/io/audit.sh`：NDJSON/CSV 解析、引号/反斜杠 fixture、BSON 上限、目标行上限。
- `tests/fuzz/json_escape_fuzz.c`：共享 JSON 转义 fuzz。
- `tests/fuzz/bson_doc_fuzz.c`：libbson 文档解析 fuzz。

## 已知限制

- CSV 控制字符由转义 fuzz 覆盖，没有端到端 pcap fixture（HTTP parser 拒绝原始控制字节）。
- BSON fuzz 覆盖 libbson 文档解析，不覆盖 Xtate BSON 文件 framing/输出。
