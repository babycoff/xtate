# Xtate 2.35.0

本次发布把离线/local 测试基础设施提升为一等能力，并加固 ZBanner 接收路径。

## 重点

- 通用 pcap 工具库和 6 套 pcap 回归矩阵。
- 本地 TLS/H2 与 QUIC/HTTP3 nightly lab。
- 解密 HTTP/3 帧 fixture（QPACK static table）。
- ZBanner 分类缓存、`banner dedup_repeat` 与 payload 契约诊断。
- 版本/报告一致性修正。

## 离线 pcap 工具

新增 `tests/pcap/lib.py`：确定性构造 Ethernet/IPv4/IPv6 TCP/UDP、校验和、
Xtate cookie 和 pcap 文件，通过 receive-only `file:` adapter 回放。

| 矩阵 | 覆盖 |
|:---|:---|
| `tests/zbanner` | SYNACK/RST/banner/重传/all-banner limit+floor/IPv6/zero-window/payload mismatch |
| `tests/http-pcap` | HTTP keyword/regex/scope/大小写/no-match |
| `tests/tcp-syn-pcap` | SYN-ACK/RST |
| `tests/http-state-pcap` | 录制明文状态化 HTTP |
| `tests/h2c-pcap` | 明文 HTTP/2 帧 |
| `tests/udp-pcap` | UDP echo cookie 响应 |

release CI 运行，无需网络、root、防火墙或目标容器。

## 加密协议测试

- `tests/lab/ci-h2.sh`：本地 TLS HTTP/2 目标。
- `tests/lab/ci-quic.sh`：本地 aioquic HTTP/3 目标。
- `.github/workflows/lab-encrypted.yml`：nightly/手动运行。
- `tests/http3-frame/`：解密 HEADERS/DATA fixture，`http3-state` 初始化时运行
  `h3_frame_selftest()`，不依赖 QUIC/TLS。
- 有意不支持 TLS/QUIC pcap 原样回放：加密握手需要 pcap 不包含的客户端/transcript 状态。

## ZBanner

- `zb_classify()` 统一 validate/handle；分类结果缓存到 `ValidPacket`，避免重复解析。
- `zbanner-policy.c` 集中 all-banner limit/floor/RST/ACK/truncated 规则，启动自检。
- `AfterFirstReply` 仍是依赖 dedup 计数的 one-shot（`repeats == 0`）；关闭去重时
  可能重复 fan-out，已在文档说明。
- banner/ACK 使用实际 `make_payload()` 长度验证；不一致时输出
  `payload_len_declared`、`payload_len_actual`、`payload_contract_error`。
- `banner dedup_repeat` 是 `banner idx` 的显式别名；`banner seqno` 才是可靠排序字段。
- `--all-banner-limit`/`--all-banner-floor` 有边界校验，floor>limit 会拒绝。

## 文档

- ZBanner 审计和精确 `banner idx` 语义。
- 离线矩阵/local lab 的测试索引。
- 文档版本统一到 2.35.0。
