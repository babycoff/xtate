# Xtate 3.0.0-rc.7

**发布候选版本——供实际试用，不是最终 3.0.0。**

本版本为 3.0 发布做准备：CI 集成、带校验和的二进制资产、真实 MCP/Agent
Skill 验收、帮助与文档修复、版本一致性检查，以及 2.44.x 迁移指南。

## 发布工程

- CI 在 Linux 上运行 MCP 契约、Agent Skill 契约、GUI、控制平面、scan-request、
  generate 与 schema/module 检查；Windows 运行同一组契约检查。
- Docker CI 任务构建 Ubuntu 24.04 全功能镜像，断言 `raw_sockets`、`http3`、
  `quic_transport`、`zstd`，并验证宿主机 GUI 页面与预检。
- tag 工作流构建 Linux/Windows 资产并附加到 GitHub Release，附 `SHA256SUMS`
  与 `BUILD-INFO`。
- `scripts/package-release.ps1` 与 `scripts/package-release.sh` 打包二进制、
  DLL、文档、schema、skills 和校验和；两者已生成随本版本发布的 rc.7 资产。
- `tests/release/test_version_consistency.py` 校验 CMake、`version.h`、二进制
  `--version`、MCP `serverInfo.version` 与文档版本横幅。

## MCP 与 Agent Skill

- 扁平 `start_scan`、未知字段拒绝、8 KiB 溢出提示、数组/字符串 `preflight`、
  真正的 `check`、JSON 转义控制 token 和 `global_args` 校验均由契约套件覆盖。
- 独立验收 15 项通过；5 项 job 生命周期检查仍因沙箱命名管道权限被阻塞。
  产品测试套件在 Windows/Linux 上覆盖完整生命周期。

## GUI 与控制平面

- 未认证不再返回 GUI 页面。打印的 URL 携带一次性引导 token，设置 HttpOnly
  SameSite cookie；API 同时接受每会话 header。
- GUI 会移除浏览器提供的 `result_path`；所有 GUI 扫描都使用服务端托管的
  `runs/<时间戳>-<序号>/` 目录。
- 控制平面方法改为精确匹配（不再子串匹配）；Unix 客户端增加 30 秒超时。
- GUI 直接用 Notepad 打开 log/result，不再等待 ShellExecute/DDE；且不会自动
  启动浏览器。

## 帮助与文档

- 长帮助按最后一个空格换行，不再从单词中间截断，也不会拆开选项名。
- 修复 `--exclude-ranges` 注册、`--tx-thread-count` 默认值、source-port 范围、
  usage 名称、分隔符和若干帮助拼写。
- 新增 `docs/migration-3.0.md` 及中文翻译，覆盖 MCP 扁平请求、结果路径、
  TUI 弃用、不再自动开浏览器、Linux-only HTTP/3/QUIC 与回滚。
- 刷新 README 模块计数、工具列表、可选依赖说明和中文模块参考。

## 兼容性

- 结果格式不变。
- 嵌套 `start_scan` 仍被拒绝；请使用扁平 scan-request 字段。
- GUI 扫描始终使用托管 run 目录；浏览器不能指定 result path。
- TUI 仍为弃用状态，不属于 3.0。

## 验证

- Windows MSVC Release 构建与完整套件：通过。
- Linux Ubuntu 24.04 构建与完整套件：通过。
- Docker 镜像构建、能力断言、宿主机 GUI 与 MCP stdio：通过。
- 发布资产与校验和：已生成并检查。
- 文档相对链接：已检查。

## 已知限制

- 无命名管道权限的沙箱无法跑完整 MCP job 生命周期；该情况报告为阻塞，
  不标记为通过。
- `preflight` 不支持 `include_file`。
- Docker 镜像无法打开宿主机文件选择器或结果查看器；请使用挂载的 `/data`
  或 GUI Results 页面。
- 最终 3.0.0 仍需用户试用与签收。
