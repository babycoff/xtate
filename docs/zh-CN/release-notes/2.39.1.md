# Xtate 2.39.1

修复 server-first TLS 组合的最后一个缺口。

## 修复

- `tls-state` 在 state 子探针没有客户端 hello 时，从 `TSP_STATE_SAY_HELLO`
  继续进入 `TSP_STATE_RECV_DATA`，读取已缓存的 server-first 应用数据。
- `mysql-state` 新增 `--after-tls`，发送 COM_PING wake-up，让 TLS 内的 MySQL
  greeting 送达。
- `managesieve-state` 新增 `--after-tls`，发送 NOOP，让 TLS 内的 capability
  greeting 送达。
- TLS 矩阵新增硬断言：

```text
mysql_version: "8.0.34"
sieve_starttls: true
```

同时保留 TLS version、ALPN 和证书 subject 断言。

## 测试

- `tests/lab/ci-tls-composition.sh`：隐式 MySQL 和 ManageSieve STARTTLS 硬断言。
- 矩阵目标改为每连接独立线程，避免陈旧握手阻塞后续用例。

## 验证

```text
nightly: TLS/STARTTLS composition success
Linux build/selftest: PASS
i18n: PASS
```

## 注意

`mysql-state --after-tls` 和 `managesieve-state --after-tls` 是 lab/兼容性唤醒，不是标准握手。MySQL 在认证前发送 COM_PING，严格服务器可能拒绝；ManageSieve 在 capability greeting 前发送 NOOP。它们只用于 TLS 组合 lab，不应作为生产环境保证。
