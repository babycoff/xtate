# Xtate 3.0.0-rc.4

这是供实际试用的**发布候选版本**，不是最终 3.0.0。正式版要等用户试用并修复问题后再发布。

RC.4 的重点是让浏览器控制台真正可用于扫描：清晰的语言切换、Xtate 自己的模块分类、
可展开的模块详情、受控的扫描级参数，以及每次扫描独立的结果目录。

## 自 3.0.0-rc.3 以来的变化

### 控制台语言与结构

- 顶栏可在**English**与**中文**之间切换整个控制台。选择保存在浏览器中，也可用
  `?lang=en` 或 `?lang=zh` 强制指定。
- 模块说明和全局参数帮助复用与 `--help`、手册相同的翻译目录。
- 页面标题改为直接表达用途：**新建扫描**、**实时扫描**、**结果**、**网卡**、
  **模块**、**系统**。装饰性的“Point, check, send”标题已移除。
- 模块分组使用 Xtate 统一名称：**Scan modules**、**Probe modules**、
  **Output modules**、**Generate modules**。

### 模块与参数查看

- 模块卡片可就地展开，显示完整说明和参数表（名称、类型、说明、别名）。
- 目录支持按名称、说明和参数搜索；`?expand=<module>` 可直接打开某个模块。
- **全局参数**提供 23 个安全的扫描级选项（seed、报文 TTL、TCP window/MSS、
  缓冲区大小、去重等），支持搜索、说明和校验。取值作为 `global_args` 发送。
- 进程、文件、脚本、控制面/job 以及会与 GUI 字段冲突的选项不会暴露。预检会在
  worker 启动前拒绝未知、类型错误或越界的值。

### 结果与文件

- 每次扫描拥有独立托管目录：`runs/<YYYYMMDD-HHMMSS>-<seq>/`，其中包含
  `scan.ndjson`、`scan.ndjson.log`、manifest 和 index。Live 与 Results 显示运行时间，
  重复扫描也能区分。
- Windows 的状态目录是 `xtate.exe` 同级、可见的 `xtate-state`；Linux 使用
  `$XDG_STATE_HOME/xtate`（含文档化的回退路径）。job 结束后请求文件会被删除。
- **Open log** / **Open result** 仍使用服务端解析的 job 路径；以管理员权限运行时
  通过 Explorer 打开控制台，避免浏览器提升权限提示。

### 验证

- Windows MSVC Release 构建、自检和完整 Windows 套件通过：i18n 一致性/覆盖、
  schema/模块校验、JSON schema 运行时、generate、control、MCP、MCP 稳定性、TUI、GUI。
- Linux 构建带 ngtcp2/GnuTLS，`http3:true`、`quic_transport:true`；Linux 套件通过
  相同的运行时检查（当前 Linux 环境没有 jsonschema，schema/模块校验仅在 Windows 运行）。
- GUI 测试覆盖语言切换、模块/选项翻译、全局参数预检接受/拒绝、每次扫描独立结果目录、
  结果分页、打开文件拒绝用例和私有令牌保护。
- 英文与中文手册的相对链接检查通过。

## 兼容性

- CLI 和 MCP 请求结构不变。`global_args` 按固定白名单校验。
- 通过 `result_path` 指定的结果文件保持原有行为；省略时使用托管运行目录。
- TUI 在 3.0 中仍标记为弃用。

## 已知限制

- HTTP/3 与 QUIC 传输仍仅限 Linux；Windows 通过 `--list-capabilities`、MCP 和控制台
  明确报告不可用。
- 预检对它校验的字段是权威的，但尚未把请求哈希绑定到 `job.start`。
- 模块参数名/取值由 worker 解析，未全部在预检中校验；全局参数已校验。
- `include_file` 路由分组和 MCP generate/stream 输入仍是后续工作。
- 控制台暂不提供每 job 磁盘配额控件或字节级结果编辑器。
- 最终 3.0.0 尚未发布。请试用 RC.4 并反馈问题。
