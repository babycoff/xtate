# Xtate 3.0.0-rc.8

**候选版本——用于手工试用，不是最终 3.0.0。**

本候选版本是 rc.7 的发布工程跟进：修复 rc.7 打标签后发现的 CI 失败，使托管 CI
的全部矩阵通过，并从已验证提交重新发布 Windows/Linux 资产。

## 相对 rc.7 的变更

- CI 已全部通过：Linux gcc/clang release/debug、ASan+UBSan、clang libFuzzer
  冒烟、MCP/Skill/GUI/控制面集成、Docker 镜像，以及 Windows 的 MSVC、
  clang-cl、MinGW UCRT64/MINGW64 四个任务。
- MinGW 可移植性：关闭 OpenSSL 时一致性排除依赖 OpenSSL 的探针；随机数使用
  可移植封装（OpenSSL、BCryptGenRandom 或 /dev/urandom）；logger 补齐 libc 头。
- ngtcp2 兼容性：当库把 BBR v2 暴露为 `NGTCP2_CC_ALGO_BBR` 时，不再因缺少
  `BBR2` 枚举而构建失败。
- 预检在链路类型探测需要 CAP_NET_RAW 时不再直接失败，而是给出明确警告，由扫描
  启动阶段做最终校验。
- libFuzzer 的 target-parser 测试补链 Windows UTF-8 工作引入的文件打开辅助函数。

rc.7 的功能集不变：扫描优先控制台、中英文界面、Xtate 模块分类与可展开详情、
23 个受校验全局参数、单次运行结果目录、托管状态目录、GUI/MCP 单命令启动、
MCP 契约加固、Docker 构建环境、带校验和资产与升级指南。
