# Xtate 3.0.0-rc.3

这是一个供实际试用的**发布候选版本**，不是最终 3.0.0。正式版本会在用户试用并修复问题后发布。

RC.3 聚焦控制台重设计，以及 RC.2 试用中反馈的文件与日志问题。

## 自 3.0.0-rc.2 以来的变更

### 控制台重设计

- 默认使用易读的 **Paper** 主题（更大字号、暖色表面、更强对比度），并可切换 **Graphite** 深色主题。主题、密度和实时刷新间隔按浏览器保存。
- **Live scan** 以醒目的状态标题开头（`Scanning`、`Scan complete`、`Scan failed`、已取消、超时或停滞），并显示计数器与最终状态说明。进度条已移除，状态和计数才是权威信息。
- Worker 日志尾部会清除终端控制字符，但保留真实的 `[HIN]`、`[ERR]` 等前缀。
- **Open log** 与 **Open result** 请求服务端用操作系统默认程序打开该任务解析后的日志或结果文件。服务端只接受 job id 与文件类型，浏览器不能提供路径。
- **Modules** 按 Scan engines、Protocol probes、Output writers、Target generators 分组，并提供计数、搜索和类型标签。
- **Settings** 改为 **System & preferences**：包含 Appearance、Runtime、Capabilities 和本地安全模型。
- 开始扫描后立即切到 Live，重置上一任务的日志、记录和轮询状态，不再显示旧任务数据。
- Method 面板可直接编辑模块参数，值以 `scan_args`/`probe_args` 发送；面板未覆盖的参数仍可通过 CLI 和 MCP 使用完整参数集。

### 文件与生命周期

- 结果和请求文件改到受管状态目录：Windows 为 `%LOCALAPPDATA%\xtate`，Linux 为 `$XDG_STATE_HOME/xtate` 或 `$HOME/.local/state/xtate`；`XTATE_STATE_DIR` 可覆盖根目录。新任务不再把结果文件写到当前目录。
- 任务进入终态后删除请求文件和心跳文件。
- 修复 Windows 非 ASCII 路径的心跳写入：心跳更新改用宽字符路径，不再残留 `.heartbeat.tmp`。
- 修复 Windows 生成结果路径被错误 JSON 反转义的问题（`C:\Users\...` 中的反斜杠不再被当作转义序列吃掉）。

### MCP 与控制面

- 私有 `xtate --gui`、`xtate --tui`、`xtate --mcp` 在环境未设置令牌时自动生成临时控制令牌。
- MCP 新增 `capabilities`、`iface.list`、`preflight` 与有界 `job.records`；结果记录支持普通文件、manifest 分片和 zstd 压缩分片。
- MCP 审计日志改为通过 `XTATE_MCP_AUDIT_LOG` 显式开启；服务端默认不再把审计日志写到当前目录。

## 兼容性

- CLI 与 MCP 请求结构除新增工具和能力字段外保持不变。
- 已有的 `--control-plane` 部署继续使用当前令牌策略；临时令牌只作用于私有 GUI/TUI/MCP 会话。
- 客户端显式提供的 `result_path` 仍按原样使用；默认路径现在进入受管状态目录。
- TUI 在 3.0 中已弃用，仅为 2.44 兼容保留。

## 验证

- Windows MSVC Release 构建、自检和回归测试通过。
- Windows 全量测试：i18n 对齐/覆盖率、schema/模块校验、JSON schema 运行时、generate、control、MCP、MCP 稳定性、TUI、GUI。
- Linux 构建启用 ngtcp2/GnuTLS 时报告 `http3:true` 和 `quic_transport:true`；Linux 测试通过 i18n、generate、control、MCP、MCP 稳定性、TUI、GUI。
- GUI 测试覆盖预检校验、受管状态目录、结果分页、打开文件拒绝场景和私有令牌保护。
- 文档检查：中英文手册无损坏的相对链接。

## 已知限制

- HTTP/3 与 QUIC 传输仍仅支持 Linux；Windows 通过 `--list-capabilities`、MCP 和控制台明确报告不可用。
- 预检对已校验字段具有权威性，但尚未把请求哈希绑定到 `job.start`。
- `include_file` 路由分组与 MCP generate/流式输入仍待后续实现。
- 控制台不提供按任务磁盘配额控制或字节级结果编辑器。
- 正式 3.0.0 尚未发布。请试用 RC.3 并反馈问题。
