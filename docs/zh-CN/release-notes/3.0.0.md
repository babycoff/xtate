# Xtate 3.0.0

Xtate 3.0.0 是 3.0 系列首个正式版。它保留 2.44.x 的扫描引擎和结果格式，并新增
扫描优先的浏览器控制台、面向 AI 宿主的类型化 MCP server、用于安全使用 MCP 的
Agent Skill、双语手册、明确的协议能力报告，以及可复现的 Linux Docker 镜像。

命令行仍是互联网测量与研究专家最主要的使用接口。GUI 和 MCP server 是同一引擎、
同一控制面上的附加客户端，不取代 CLI。

## 主要特性

- **扫描优先浏览器控制台。** 新建扫描、运行中视图、结果、网卡、模块和系统页面；
  服务端预检；每次扫描独立的托管结果目录；中英文界面；默认仅监听环回，远程访问
  必须显式开启。
- **MCP server。** 通过私有控制面提供 14 个类型化工具：发现、路由检查、预检、
  配置校验、托管扫描 job、有界结果读取和取消。不调用 shell、不内联结果、不监听
  TCP。
- **Agent Skill。** `skills/xtate/` 教外部 agent 安全使用 MCP server；它只是
  MCP 使用指南，不是安全边界。
- **命令行。** 稳定的 scan/probe/output/generate 模块模型、路由感知的
  `--explain-target`/`--check`、job 控制面客户端、离线与可复现目标输入，以及
  interactive 控制台。
- **协议。** HTTP/1.1 与 HTTP/2 state 探针；Linux 上 HTTP/3 与 QUIC 传输；TLS
  组合、STARTTLS、DNS/DoT/DoH、SSH KEX、邮件、数据库和工业协议探针；Windows
  明确报告 HTTP/3/QUIC 不可用。
- **测量运维。** JSON/NDJSON 输出、分片结果、zstd（取决于构建）、配额、保留策略、
  流控，以及包含全部可选依赖的 Ubuntu 24.04 Docker 镜像。

## 默认值与速率

所有界面的默认扫描速率都是 **100 包/秒**。

Xtate 本身接受正的小数和极高的速率。例如 `-rate 0.5` 表示每两秒发送一个包，
`-rate 1000000` 在合适的硬件和路径上也是合法的高速测量值。浏览器 GUI 将速率
输入限制在 1–10,000，这是 **GUI 稳定性限制，不是引擎限制**。专家的高速测量应使用
命令行、MCP 或控制面，那里没有人为上限。

interactive 控制台会即时校验 `set rate`，但不设上限。它新增 `check`、结构化的
`set-subprobe`/`set-subprobe-arg`、`history clear`，以及 scan/probe 兼容性提示。
Windows 上控制台会明确说明扫描结束后不能自动重启，需要再次运行
`xtate -interactive`。

## 结果与控制面

- 结果是分片 NDJSON 加 manifest；客户端按页读取，不加载整个文件。
- job 有明确的生命周期、心跳、卡住检测、超时与取消。
- 控制面仅本地：Linux 用 Unix socket，Windows 用 Named Pipe。多个进程共享端点时
  应设置 `XTATE_CONTROL_TOKEN`。
- MCP 不暴露网络监听。Claude Desktop、Cursor、VS Code 等常用 stdio 宿主配置见
  [MCP server](../mcp-server.md)。

## 兼容与升级

- 2.44.x 的结果文件、目标文件和配置键继续可读。
- 3.0 用浏览器控制台取代旧 TUI；使用 `--tui` 的脚本应迁移到 `--gui`。TUI 仅作为
  已弃用的兼容客户端保留，不在 3.0 手册中。
- 新的全局参数与模块参数均为增量。完整迁移清单见[迁移到 3.0](../migration-3.0.md)。
- GUI 默认仅本地。绑定非环回地址需要 `XTATE_GUI_ALLOW_REMOTE=1`；Host 头仍会
  校验，会话 token 仍必需。

## 已知限制

- Windows 不提供 HTTP/3 或 QUIC 传输，能力报告会明确说明。
- 原始 L2 扫描需要链路类型受支持的抓包网卡；Linux `loopback` 没有 Ethernet MAC。
  请使用 on-link 目标和真实抓包网卡。
- Linux banner/state 扫描期间需要按文档启用防火墙/RST 抑制规则。
- Linux 压缩包动态链接发行版库；Docker 镜像才是自包含方案。Ubuntu 24.04 运行时
  依赖：

  ```bash
  sudo apt install libssl3 libpcre2-8-0 libxml2 libbson-1.0-0 \
    libmongoc-1.0-0 zlib1g libzstd1 libngtcp2-9 \
    libngtcp2-crypto-gnutls2 libgnutls30t64 libpcap0.8
  ```

- 高速率取决于网卡、驱动和路径。文档中的大规模速率是操作参考，不是保证值。
