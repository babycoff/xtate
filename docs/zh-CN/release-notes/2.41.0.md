# Xtate 2.41.0

新增 DNS over TLS、DNS over HTTPS（HTTP/1.1 与 HTTP/2）、HPACK Huffman 解码、
可重复 DNS transport lab，以及按操作系统区分的防火墙提示。

## DNS 探针

### DoT

新增 `dot` state 子探针：

```text
tcp-state -> tls-state (ALPN dot) -> dot
```

发送 RFC 7858 的 2 字节长度前缀并解析 DNS 响应：

```text
dot_dns_len
dot_rcode
dot_ad
dot_answer
dot_rrsig_count
dot_dnskey_count
dot_ds_count
dot_nsec_count
dot_dnssec_present
```

### DoH

新增 `doh`（HTTP/1.1）和 `doh-h2`（HTTP/2）：

```text
doh:    tcp-state -> tls-state (ALPN http/1.1) -> doh
doh-h2: tcp-state -> tls-state (ALPN h2)       -> doh-h2
```

两者都 POST `application/dns-message` 并输出：

```text
doh_status
doh_content_type
doh_dns_len
doh_rcode
doh_ad
doh_answer
doh_rrsig_count
doh_dnskey_count
doh_ds_count
doh_nsec_count
doh_dnssec_present
```

`doh-h2` 复用 HTTP/2 HPACK 解码器，并支持 RFC 7541 Huffman。
`--doh-host` 默认使用目标 IP；`doh-h2` 在 DoH 模式下默认路径为 `/dns-query`。

## 测试与防火墙

- `tests/lab/ci-dns-transport.sh` 启动 DoT、DoH HTTP/1.1、DoH HTTP/2 目标，
  断言 `dot_rcode`、`doh_status: 200`，以及不存在 `h2_hpack_decode_failed`。
- Linux 防火墙提示只针对 stateful 扫描（`zbanner`、`tcp-state`、state 子探针）。
  `tcp-syn` 和 UDP/DNS 不需要 Linux RST 规则。
- Windows 不输出防火墙警告；`tcp-syn` 只提示 `-scan-arg "--send-rst"`。
- 文档：`docs/firewall.md`、`docs/dns-over-tls.md`、
  `docs/dns-over-https.md`（中英文）。

## 注意事项

- 未实现 DoH HTTP/3。
- DoT/DoH 是 state 子探针，必须配合 `tls-state`。
- DNSSEC 字段是部署证据，不是完整链验证。
