# Xtate 2.44.0 发布说明

发布于 2026-11-13。

## 亮点

### 控制平面浏览器 GUI

Xtate 新增本地浏览器任务面板：

```bash
xtate --control-plane=/tmp/xtate-ctl.sock
# 另一个终端；如果设置了 XTATE_CONTROL_TOKEN，需要相同值：
xtate --gui --control-connect=/tmp/xtate-ctl.sock
```

GUI 是又一个控制平面客户端，不会在进程内扫描。它列出任务，每三秒刷新状态、
计数、stderr 尾部和结果 manifest，确认后可取消任务，并通过向导启动一个小型已授权
扫描（模块、目标、端口、速率、超时、结果路径和可选接口）。

页面编译进二进制，由只绑定 `127.0.0.1` 的微型 HTTP server 提供。每次运行生成新的
128 位会话 token，注入页面并要求每个 API 请求携带。服务端校验 `Host` 是否为环回
（防 DNS rebinding），设置 Content-Security-Policy，并且只转发 `job.list`、
`job.status`、`job.cancel`、`job.result_manifest` 和 `job.start`。
`job.start` 还要求服务端看到 `params.authorized: true`。

用 `--gui-listen=127.0.0.1:PORT` 指定端口（`:0` 自动选择），
`--gui-no-open` 跳过打开浏览器。GUI 需要已运行的控制平面，自己不会启动控制平面。

向导刻意只覆盖 `start_scan` 的一个子集：不支持 `include_file`、
`probe_args`/`scan_args`、zstd 和配额设置。这些请使用 MCP 或扫描请求文件。

## 兼容性

- 既有 CLI、MCP 和控制平面请求不变。
- 新增 `--gui`、`--gui-listen`、`--gui-no-open`；`--gui` 必须配合
  `--control-connect`，且不会启动控制平面。
- 版本字符串、`--version` 与 MCP `serverInfo.version` 均报告 `2.44.0`。

## 已知限制

- GUI 仅限本机，只绑定环回，没有 TLS。不要把端口暴露出去。
- GUI 启动向导不覆盖完整扫描请求字段（见上）。
- GUI 不流式传输结果记录；它展示 manifest，分片读取仍由扫描器 CLI、MCP 资源或
  自定义读取器完成。
- 存在多个默认接口时，worker 可能报 `multiple default interfaces detected`；
  先运行 `xtate --explain-target=<target>`，把报告的接口填入向导。
- 某些 VPN 适配器使用链路类型 `RAW`，Xtate 无法用于原始扫描；请先预检目标并选择
  受支持的抓包接口。
- 取消是尽力而为；worker 已退出时返回 `"cancelled": false`。
- 本地控制传输的控制 token 可选。若其他本地用户可访问 socket/pipe，请设置
  `XTATE_CONTROL_TOKEN`。
- MCP 仍只暴露静态 `targets`/`include_file`；generate/stream 输入未通过 MCP 暴露。

## 升级说明

无需迁移。既有控制平面、任务、MCP 和结果文件保持兼容。GUI 的结果路径由控制平面
进程解释，不由 GUI 进程解释。
