Security

The server binds to 127.0.0.1 only, validates the Host header, requires a per-session token, and exposes only allowlisted control methods. The scan child is owned by the control plane.

The GUI never stores the control token in the page; the server adds it to control requests.

Authorization is checked before start and again by the server. Do not scan systems you do not own.
