Security model
loopback only

The server binds to 127.0.0.1 only, validates the Host header, requires a per-session token, and exposes only allowlisted control methods. The scan child is owned by the control plane.

The GUI page never receives the control-plane token; the server adds it to control requests. Authorization is checked before Start and again by the server.

Result and log files stay under the managed Xtate results directory, not beside the binary.
